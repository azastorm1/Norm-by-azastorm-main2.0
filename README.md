# Norm by Azastorm — сайт-магазин с админ-панелью

Сайт на трёх языках (русский, узбекский, английский), конструктор футболки, предзаказ,
проверка статуса заказа и админ-панель. Заказы приходят в админку.

Внешних библиотек нет: нужен только **Node.js 18 или новее**.

## Быстрый старт

1. Установите Node.js (LTS) с https://nodejs.org, если его ещё нет.
2. Запустите `start-windows.bat` (Windows) или `start-mac-linux.command` (Mac/Linux) двойным кликом. Сайт откроется на http://localhost:3000.
3. Админка: http://localhost:3000/admin, пароль лежит в файле `.env` (строка `ADMIN_PASSWORD`). Его можно поменять там же.

## Что внутри

- `server.js` — сервер и база данных (один файл `data/db.json`)
- `public/` — сайт (`index.html`, `app.js`, `i18n.js`, `style.css`) и админка (`admin.html`, `admin.js`, `admin.css`)
- `data/` — создаётся при первом запуске: база и загруженные фото. **Эту папку надо сохранять и копировать для резерва.**

## 1. Запуск на своём компьютере (проверить)

1. Установите Node.js с https://nodejs.org (версия LTS).
2. Распакуйте архив. Скопируйте файл `.env.example` в `.env` и откройте его в блокноте.
3. В `.env` задайте `ADMIN_PASSWORD` — длинный пароль для входа в админку.
4. В папке проекта выполните: `node server.js`
5. Откройте http://localhost:3000 (сайт) и http://localhost:3000/admin (админка).

## 3. Как выложить в интернет

Нужен сервер, где работает Node.js, и **постоянная папка для данных**. Без неё заказы и фото пропадут при перезапуске.

**Вариант А. Обычный VPS (Ubuntu), самый надёжный.**
1. Арендуйте VPS, установите Node.js 18+ (с nodejs.org или через менеджер пакетов).
2. Загрузите проект, создайте `.env`, укажите `PUBLIC_URL=https://ваш-домен`.
3. Запуск в фоне: `npm i -g pm2`, затем `pm2 start server.js --name norm`, `pm2 save`, `pm2 startup`.
4. HTTPS и домен: установите Caddy и в `Caddyfile` напишите `ваш-домен { reverse_proxy localhost:3000 }`. Сертификат получится автоматически.

**Вариант Б. Облачные сервисы (Render, Railway и подобные).** Выберите платный план с постоянным диском (Persistent Disk / Volume), подключите диск, например, в `/data` и задайте переменную `DATA_DIR=/data`. Команда запуска: `node server.js`. Переменные из `.env` вносятся в настройки сервиса. Бесплатные планы без диска не подходят.

После запуска зайдите на `/admin` и заполните данные (см. ниже).

## 4. Первое заполнение в админке

1. **Цены и настройки:** цена футболки, принта, вышивки, свой дизайн клиента; цвета (названия на 3 языках); размеры; Instagram, Telegram, телефон; сроки, оплата, доставка. Пока цена футболки равна 0, на сайте написано «Цена уточняется».
2. **Фото заготовок:** загрузите фото каждой футболки спереди и сзади, подвиньте красную рамку (область рисунка). Без фото сайт показывает нарисованную футболку.
3. **Дизайны:** добавьте свои работы (фото, названия, доплата). Раздел появится на сайте, когда будет хотя бы один дизайн.
4. **Заказы:** смотрите макет, фото клиента, меняйте статус, пишите заметки. Клиент по номеру заказа и телефону видит статус на сайте.

## Безопасность

- Админка защищена паролем из `.env`; после 5 неверных попыток вход блокируется на 10 минут.
- Используйте HTTPS (вариант А с Caddy) и длинный пароль.
- Делайте резервную копию папки `data/`.
- Загрузки принимаются только как PNG, JPEG, WEBP.

## Что стоит проверить

- Узбекские и английские тексты в `public/i18n.js` писались без носителей. Покажите их человеку, знающему язык.
- Макет заказа создаётся в браузере клиента; шрифт надписи в нём может отличаться от сайта.
- Онлайн-оплаты нет: условия оплаты вы пишете в настройках и обсуждаете с клиентом.
